# Localized Routes

This folder structure is used according to
the ["next-intl with routing"](https://next-intl.dev/docs/getting-started/app-router/with-i18n-routing)
documentation.  
The trick with `[...rest]/page.tsx` is needed to handle error pages.
Read more about it in the
["next-intl / error-files"](https://next-intl.dev/docs/environments/error-files)
documentation.
